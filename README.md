# EDMOX

Sitio de Ediciones Mox en React + TypeScript (Vite + MUI).

## Requisitos

- Node.js 24 (ver `.nvmrc`)

## Desarrollo

```bash
npm install
npm run dev
```

Antes de hacer commit: `npm run check`.

Las convenciones del proyecto (estructura, reglas de textos/colores/rutas, cómo agregar piezas, formato de commits) están en [`CLAUDE.md`](./CLAUDE.md).

## Build (Netlify)

```bash
npm run build
```

En Netlify:

- **Build command**: `npm run build`
- **Publish directory**: `dist`
